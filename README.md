# Live Property – Real Estate Website

Live Property is a modern real-estate website designed to help users discover properties for buying, renting, and investment. The website provides a clean and professional interface with property listings, search options, property categories, and an informative About Us section.

## Project Overview

Live Property is designed as a real-estate platform where users can explore different types of properties and find suitable options based on location, property type, and budget.

The homepage includes a hero section with the heading "Find Your Dream Property for a Better Tomorrow", along with featured property cards and property information.

## Features

* Modern real-estate landing page
* Property search interface
* Location selection
* Property type selection
* Budget selection
* Residential properties
* Commercial properties
* Investment opportunities
* Trusted and Transparent section
* Featured property listings
* Property details including:

  * Location
  * Price
  * Number of beds
  * Area in square feet
  * Number of rooms
* About Us section
* Social media icons
* Hover effects
* Gradient buttons
* Sticky navigation bar
* Clean and professional UI

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Remix Icon

The project uses Google Fonts for typography and Remix Icon for interface icons.

## Design

The website uses a professional color combination:

* Primary Color: `#0E2954`
* Secondary Color: `#FF7A00`
* Background Color: White
* Hero Section Color: `#13417C`

The CSS includes custom hover effects, gradients, shadows, borders, Flexbox layouts, and background images.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/live-property.git
```

2. Open the project folder.

3. Make sure the `images` folder is present in the project directory.

4. Open `index.html` in your browser.

You can also use Visual Studio Code with the Live Server extension for development.
